# Dad's Art Portfolio Website

## Core Features

### 1. Artwork Gallery
- Display art pictures with detailed information
- Each artwork shows:
  - Author's purpose/intention
  - Description/story
  - Canvas size
  - Other relevant metadata
- **QR Code Integration**: On-site museum visitors scan QR codes on physical artworks → redirects to website with specific artwork details

### 2. Contact Form
- Visitors can fill out business inquiry form
- Submissions sent to admin email

### 3. Exhibition Announcements (전시회)
- Display upcoming exhibition information
- Show dates and details

## User Roles

- **Administrator** (1): Full CRUD access for artworks, info, announcements
- **Visitors**: View-only access, no login required

## Primary Use Case
Museum visitors scan QR codes on physical artworks to instantly view detailed information about the piece they're viewing on their mobile device.
